# Tomato Disease Detection

A deep learning model that classifies tomato leaf diseases and suggests treatments.

## Classes
The model can identify 10 conditions:
- Bacterial Spot
- Early Blight
- Late Blight
- Leaf Mold
- Septoria Leaf Spot
- Spider Mites
- Target Spot
- Yellow Leaf Curl Virus
- Mosaic Virus
- Healthy

## Model
- CNN trained on the PlantVillage dataset (Kaggle)
- 93% training accuracy, 90% validation accuracy after 20 epochs

## Dataset
[PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)

## How to Run
Open `tomato_disease_detection.ipynb` in Google Colab and follow the steps in the notebook.
